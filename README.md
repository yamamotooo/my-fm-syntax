# My FM Syntax

FileMaker スクリプトのテキスト書き出しに対して、キーワードの色分けとコメントの強調表示を提供する VS Code 拡張機能です。`.txt` として保存されたスクリプトログを読みやすく確認できます。

## 主な機能

- `If`、`Loop`、`Set Field` など主要なスクリプトステップを色分け
- `#` で始まるコメント行を淡色表示
- ブロック構造を保ったままインデントを維持

## 使い方

1. VS Code で FileMaker から書き出したスクリプトファイル（`.txt`）を開く  
2. ステータスバー左下で言語モードが `FileMaker` になっていることを確認  
3. 必要に応じて `Ctrl+K M` (`⌘K ⌘M`) で言語モードを `FileMaker` に変更

## 既知の問題

- カスタム関数やプラグイン固有ステップは未対応
- FileMaker の UI からコピーしたリッチテキストはサポート対象外
